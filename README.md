# Welcome to ds3dl. The purpose of this codebase is to host a daily dark souls 3 challenge similar to many other dls websites.

# Every day the set of games will reset and you can play the daily game again.

# Different games to play

## Character guesser - Guess the character based on the following attributes: Health | Type | Location(s) | Runes | Resistances

### Input a character / enemy / boss name and get the following info to guide your guesses

#### Health - up or down arrow

#### Type - Red if type is wrong. Green if correct.

#### Location(s) - Red if wrong entirely. Yellow if some of the locations overlap. Green if all locations are correct

#### Runes - up or down arrow

#### Resistances - Red if resistance is wrong. Yellow if some of the resistances overlap. Green if all resistances are correct
